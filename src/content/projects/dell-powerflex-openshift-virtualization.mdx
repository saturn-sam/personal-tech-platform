## Project Overview

This project documents a virtualization modernization path using OpenShift Virtualization with Dell PowerFlex-backed storage. The primary concern is predictable VM storage behavior across provisioning, migration, backup, and recovery.

## Implementation Details

The implementation model maps VM workload classes to storage classes and operational checks. Storage behavior is treated as an explicit platform contract so VM owners understand performance and recovery expectations before production placement.

<Callout type="note" title="Storage contract">
  Storage class selection should include recovery behavior, snapshot support, and migration
  compatibility, not only capacity and availability.
</Callout>

## Challenges

- Aligning VM performance expectations with storage class capabilities.
- Documenting backup and restore ownership across platform and storage teams.
- Validating migration behavior before shared VM templates are published.

## Lessons Learned

- VM platform design needs storage validation as early as workload discovery.
- Recovery assumptions should be tested before production migration.
- Operational documentation reduces ambiguity between virtualization and storage teams.
