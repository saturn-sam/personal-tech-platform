## Why It Matters

Private cloud operations depend on management services that are easy to overlook during normal workload delivery. A recurring review keeps lifecycle, backup, certificate, network, and ownership risks visible.

## How to Use This Resource

Use this template before lifecycle events, expansion work, and recovery reviews. Record the review outcome in the project or architecture asset that owns the platform decision.

## Review Areas

| Area      | Review question                           | Evidence            |
| --------- | ----------------------------------------- | ------------------- |
| Lifecycle | Is the validated release bill documented? | Upgrade plan        |
| Backup    | Are management components recoverable?    | Restore test record |
| Network   | Are routing and DNS dependencies known?   | Dependency map      |
| Ownership | Are escalation paths current?             | Operations baseline |

## Related Practice

Use this resource with the VMware Cloud Foundation project and secure platform operations baseline. The review should support operating discipline, not add paperwork.
