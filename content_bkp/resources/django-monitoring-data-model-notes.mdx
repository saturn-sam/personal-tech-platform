## Why It Matters

Monitoring tools are useful only when the data model reflects operator questions. Inventory, health checks, and reports should be modeled so ownership and history remain clear.

## How to Use This Resource

Use these notes before building dashboards or report views. Define the records operators need to trust before deciding how the interface should present them.

```python
class HealthObservation(models.Model):
    asset = models.ForeignKey("InventoryAsset", on_delete=models.CASCADE)
    observed_at = models.DateTimeField()
    status = models.CharField(max_length=32)
    summary = models.TextField()
```

## Modeling Questions

- Which infrastructure asset owns the health observation?
- Which observation fields support reporting instead of only display?
- Which status values trigger operational follow-up?
- How long should historical observations remain queryable?
