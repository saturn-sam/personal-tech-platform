# PTKP Maintenance Prompt

Task: Annual Platform Review

Status: Approved

---

# Purpose

Perform a comprehensive annual review of the Personal Technical Knowledge Platform (PTKP) to evaluate its architecture, content, engineering quality, documentation, performance, security posture, and long-term maintainability.

This review is strategic in nature and should guide the platform roadmap for the next year.

No implementation work should be performed during this review.

---

# Required Reading

Before beginning, read and follow:

- AGENTS.md
- docs/PROJECT_SPEC.md
- docs/CONTENT_GUIDE.md
- docs/AUTHORING_GUIDE.md
- docs/CONTENT_STYLE_GUIDE.md
- docs/OPERATIONS_RUNBOOK.md
- docs/MAINTENANCE_SCHEDULE.md
- docs/FUTURE_ENHANCEMENTS.md

These documents are authoritative.

---

# Objective

Evaluate the overall health of PTKP and identify opportunities for long-term improvement while preserving the existing architecture.

---

# Architecture Review

Review:

- Overall architecture
- Information architecture
- Component architecture
- Design System
- Content Model
- Search architecture
- Build pipeline
- Deployment architecture

Identify strengths, weaknesses, and future risks.

---

# Content Review

Evaluate:

- Technical accuracy
- Content freshness
- Metadata quality
- Internal linking
- Knowledge coverage
- Content balance
- Documentation quality

Recommend content priorities for the next year.

---

# Engineering Review

Review:

- Code quality
- Project structure
- Dependency health
- Build process
- Static generation
- Search implementation
- Cloudflare Pages compatibility

---

# Performance Review

Measure and document:

- Lighthouse Performance
- Accessibility
- Best Practices
- SEO
- Bundle size
- Build time
- Search performance

Compare against previous annual reviews.

---

# Accessibility Review

Verify continued compliance with:

- WCAG 2.2 AA
- Semantic HTML
- Keyboard navigation
- Screen reader compatibility

---

# Documentation Review

Review every document under:

- docs/
- prompts/

Identify outdated or duplicate documentation.

---

# Technical Debt

Identify:

- Obsolete patterns
- Refactoring opportunities
- Duplicate content
- Outdated dependencies
- Documentation gaps

Prioritize by impact.

---

# Platform Roadmap

Review:

- Future Enhancements
- Deferred Features
- Platform Goals

Recommend priorities for the next development cycle.

---

# Deliverables

Provide:

1. Executive Summary
2. Platform Health Score
3. Architecture Assessment
4. Engineering Assessment
5. Content Assessment
6. Documentation Assessment
7. Technical Debt Summary
8. Roadmap Recommendations
9. Validation Results

---

# Out of Scope

Do not:

- Implement new features
- Refactor code
- Update dependencies
- Modify architecture

---

# Expected Output

Produce a comprehensive annual platform review report with prioritized recommendations for the next year's roadmap.
