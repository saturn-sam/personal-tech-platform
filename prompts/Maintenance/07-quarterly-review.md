# PTKP Maintenance Prompt

Task: Quarterly Platform Review

Status: Approved

---

# Purpose

Perform a comprehensive quarterly review of the Personal Technical Knowledge Platform (PTKP) to ensure long-term quality, consistency, maintainability, and architectural integrity.

No new features or architectural changes are permitted during this review.

---

# Required Reading

Before beginning, read and follow:

- AGENTS.md
- docs/PROJECT_SPEC.md
- docs/CONTENT_GUIDE.md
- docs/OPERATIONS_RUNBOOK.md
- docs/MAINTENANCE_SCHEDULE.md
- docs/FUTURE_ENHANCEMENTS.md

These documents are authoritative.

---

# Objective

Review the overall health of PTKP and identify improvements that should be planned for future work.

---

# Architecture Review

Verify:

- Information Architecture
- Content Model
- Component Library
- Design System
- Routing
- Content Collections

Confirm architectural consistency.

---

# Content Review

Review:

- Articles
- Lab Notes
- Architecture Guides
- Projects
- Technologies
- Certifications
- Resources
- Learning Paths

Verify:

- Metadata
- Internal links
- Categories
- Tags
- Relationships
- Content quality

---

# Platform Review

Verify:

- Homepage
- Navigation
- Search
- Breadcrumbs
- Dynamic routes
- Responsive layouts

---

# Documentation Review

Review:

- README
- PROJECT_SPEC
- Runbooks
- Guides
- Prompt library

Confirm all documentation is current.

---

# Dependency Review

Review:

- Astro
- Node.js
- npm packages
- Security advisories

Document recommended updates.

---

# Performance Review

Measure:

- Lighthouse Performance
- Accessibility
- SEO
- Best Practices
- Bundle size

Compare results with previous review.

---

# Accessibility Review

Verify:

- Keyboard navigation
- Focus management
- Semantic HTML
- Screen reader compatibility
- WCAG 2.2 AA compliance

---

# Technical Debt Review

Identify:

- Refactoring opportunities
- Deprecated patterns
- Duplicate logic
- Documentation gaps

Prioritize by impact.

---

# Future Enhancements

Review:

- Enhancement backlog
- Deferred features
- Architectural implications

Recommend priorities.

---

# Deliverables

Provide:

1. Executive summary
2. Platform health assessment
3. Issues identified
4. Recommended improvements
5. Technical debt summary
6. Enhancement priorities
7. Validation results

---

# Out of Scope

Do not:

- Implement features
- Refactor code
- Update dependencies
- Modify architecture

---

# Expected Output

Produce a quarterly platform review report with prioritized recommendations for the next development cycle.
